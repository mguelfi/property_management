Front desk — 3 mockups

Same check-in / front-desk workflow (arrivals, room assignment, check-in, checkout, walk-in registration), three different design directions. Open each full-page, or check a box below to line them up side by side.

Option A

Dense ops dashboard

Dark command-center layout with a persistent nav rail and data-dense tables. One accent color is reserved strictly for clickable actions, a second for "needs attention" flags — everything else is plain neutral text. Editable fields get an inset, bordered "well" so they never look like buttons or plain data.

Open full page →
Option B

Kanban board

Trello-style columns of guest cards with a colored top-stripe per column. Actions live in a footer button row on each card; the card body itself is pure read-only text. Anything fillable — assigning a room, registering a walk-in — opens in a slide-over drawer, so the board is 100% "read + act" and the drawer is 100% "fill in."

Open full page →
Option C

Guided step-by-step wizard

A task-first landing screen (Check in / Check out / Register walk-in) leads into a numbered, single-column stepper — one primary action per screen. Only one accent color exists, used solely for that action; read-only summaries sit in borderless gray cards, fillable fields in bordered white ones.
